# Dev Agent Bot — личный AI-агент разработчика в Telegram (полностью локальный)

## Что делает
- Отвечает в Telegram как обычный бот.
- В свободное время (раз в N часов, задаётся в .env) сам изучает
  следующую тему из `topics.py` через ЛОКАЛЬНУЮ модель (Ollama —
  работает прямо на твоём VPS, без обращения к облаку и без оплаты
  за токены) и присылает тебе краткий конспект.
- Ты подтверждаешь кнопкой ✅ — тема добавляется в постоянную память
  (`data/knowledge_base.json`), либо ❌ — пропускается навсегда.
- Кнопка «📚 Мои модули» — список всего, что уже изучено и подтверждено.
- Кнопка «🎓 Изучить сейчас» — не ждать расписания, изучить сразу.

## Важно про качество на 4 ГБ RAM
Модель `qwen2.5:1.5b-instruct` — маленькая, влезает в 4 ГБ без GPU.
Она заметно проще и иногда менее точна, чем облачные модели вроде
Claude/GPT — для коротких обучающих конспектов этого достаточно, но
не жди экспертного уровня объяснений. Если апгрейднешь VPS до 8+ ГБ —
смени `OLLAMA_MODEL` в `.env` на что-то посерьёзнее (например
`qwen2.5:7b-instruct` или `llama3.1:8b`).

## Запуск на VPS (Ubuntu + Docker Compose)

1. Скопируй папку `dev-agent-bot` на сервер:
   ```bash
   scp -r dev-agent-bot root@ВАШ_IP:/opt/dev-agent-bot
   ```

2. На сервере создай `.env`:
   ```bash
   ssh root@ВАШ_IP
   cd /opt/dev-agent-bot
   cp .env.example .env
   nano .env
   ```
   Впиши только `TELEGRAM_BOT_TOKEN` (токен от @BotFather) —
   остальное уже настроено для локальной модели.

3. Подними всё одной командой (соберёт бота и скачает Ollama):
   ```bash
   docker compose up -d
   ```

4. Скачай саму модель внутрь контейнера ollama (один раз,
   займёт немного времени и трафика на скачивание, дальше всё
   работает офлайн):
   ```bash
   docker exec -it ollama ollama pull qwen2.5:1.5b-instruct
   ```

5. Перезапусти бота, чтобы он точно подхватил готовую модель:
   ```bash
   docker compose restart bot
   ```

6. Проверь логи:
   ```bash
   docker compose logs -f bot
   ```
   Должна быть строка `Бот запущен, жду сообщений...`.

7. В Telegram напиши боту `/start`.

## Как получить токен бота (если ещё не делал)
1. В Telegram напиши @BotFather
2. `/newbot`, укажи имя и username (должен заканчиваться на `bot`)
3. Получишь токен вида `123456789:AAH...` — это и есть `TELEGRAM_BOT_TOKEN`

## Если модель не помещается / всё виснет
На 4 ГБ RAM полезно проверить, не упирается ли сервер в память:
```bash
docker stats
```
Если `ollama` съедает всю память и падает — можно попробовать ещё
меньшую модель: `docker exec -it ollama ollama pull llama3.2:1b` и
поменять `OLLAMA_MODEL` в `.env`.

## Изменение списка тем
Редактируй `topics.py` — просто список строк, порядок = порядок изучения.

## Остановка / обновление
```bash
docker compose down
# поправь код
docker compose up -d --build
```
