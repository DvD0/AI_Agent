# TG Dev Agent — личный ИИ-агент разработчика в Telegram

Что делает:
- Отвечает на вопросы по веб/game/mobile-разработке в Telegram.
- В фоне (по расписанию) сам генерирует учебные заметки по темам из
  `bot/curriculum.py`, по кругу — веб, игры, мобильная разработка.
- Ничего не запоминает автоматически: новая тема приходит тебе с двумя
  кнопками — "Добавить в память" / "Пропустить". Только подтверждённые
  темы учитываются в дальнейших ответах бота.
- Память переживает перезапуск контейнера (SQLite в volume `./data`).

## Что нужно перед запуском

1. **Токен Telegram-бота**: в Telegram напиши `@BotFather` → `/newbot`,
   следуй инструкциям, получишь токен вида `123456:ABC-DEF...`.
2. **Свой Telegram ID**: напиши `@userinfobot`, он пришлёт твой числовой
   ID — это защитит бота от чужих сообщений.
3. **Anthropic API-ключ**: на https://console.anthropic.com/ →
   API Keys → Create Key.

## Установка на VPS (Ubuntu + Docker)

```bash
# 1. Скопируй папку tg-dev-agent на сервер, например через scp:
scp -r tg-dev-agent root@ВАШ_IP:/opt/

# 2. Зайди на сервер
ssh root@ВАШ_IP
cd /opt/tg-dev-agent

# 3. Заполни .env
cp .env.example .env
nano .env
#   TELEGRAM_BOT_TOKEN=...
#   ANTHROPIC_API_KEY=...
#   ALLOWED_USER_ID=...

# 4. Запусти
docker compose up -d --build

# 5. Проверь логи
docker compose logs -f
```

## Использование

1. В Telegram найди своего бота (по имени, которое дал BotFather),
   нажми Start / отправь `/start`.
2. Бот запомнит твой chat_id и будет присылать уведомления о новых
   изученных темах туда же.
3. `/modules` — посмотреть темы, ждущие подтверждения.
4. `/memory` — что уже подтверждено.
5. Просто пиши вопросы по разработке в чат — обычный режим общения.

## Настройка частоты самообучения

В `.env`: `STUDY_INTERVAL_HOURS=6` — раз в сколько часов агент
генерирует новую тему. Список тем — в `bot/curriculum.py`, можно
редактировать/дополнять под свои интересы (сейчас там смесь web/game/
mobile, как ты просил).

## Ограничения текущей версии (честно)

- Агент "изучает" темы через сам Claude API (используя его встроенные
  знания), а не через реальный веб-поиск — если нужен именно живой
  поиск свежих статей, это отдельная доработка (добавить веб-поиск
  инструмент в `claude_client.py`).
- Хранится история последних 12 сообщений чата для контекста — не
  безлимитная память диалога.
- Один бот = один владелец (`ALLOWED_USER_ID`). Не рассчитан на
  нескольких пользователей одновременно.
